## Proje Hakkında

Bu proje, güncel hava durumu verilerini **Open-Meteo API** üzerinden çekerek kullanıcıya sunan bir hava durumu uygulamasıdır.

Proje iki farklı yapıdan oluşmaktadır:

- **Konsol Uygulaması:** Open-Meteo API üzerinden güncel hava durumu verilerini alarak kullanıcıya sunar.
- **Web Uygulaması:** Güncel hava durumu bilgilerini kullanıcı dostu bir arayüz üzerinden görüntüler.

Web arayüzünün tasarımında **Bootstrap** kullanılmıştır. API üzerinden alınan güncel veriler dinamik olarak işlenerek kullanıcıya gösterilmektedir.

## Kullanılan Teknolojiler

- C#
- .NET
- ASP.NET Core
- Open-Meteo API
- Swagger
- Bootstrap
- HTML / CSS

## Projenin Amacı

API kullanımı, güncel veri çekme, backend işlemleri ve web arayüzü geliştirme konularında pratik kazanmak amacıyla geliştirilmiştir.
